# Кагэмиюра · Kagemiyura

Личная ИИ-помощница с русским интерфейсом, чёрно-золотым оформлением и Cloud.ru. Сервер и интерфейс написаны на TypeScript; сторонних библиотек во время работы нет. История хранится в SQLite, встроенной в Node.js; отдельный сервер базы данных не нужен.

## Запуск в Windows

1. Скачайте репозиторий: **Code → Download ZIP**, распакуйте архив целиком в отдельную папку на компьютере или внешнем SSD.
2. Запустите **`Kagemiyura.bat`** двойным нажатием. Первая подготовка требует интернета.
3. Дождитесь открытия браузера. В разделе **Настройки** вставьте ключ Cloud.ru и нажмите **Сохранить**.
4. Нажмите **Загрузить список**, выберите текстовую модель и снова сохраните настройки. При желании нажмите **Проверить модель**.
5. Откройте чат и отправьте сообщение.

Не переносите BAT отдельно от остальных файлов. Администратор, Python и Docker не нужны. Требуется 64-разрядная Windows 10/11 и Windows PowerShell 5.1. Поддерживаются x64 и ARM64; CI проверяет x64.

BAT использует совместимый Node.js 24+ с npm, если он установлен. Иначе скачивает закреплённый Node.js 24.22.2 с `nodejs.org`, проверяет SHA-256 и распаковывает его в `.runtime/node`. Системные установки и глобальная политика PowerShell не меняются. Зависимости устанавливаются строго по `package-lock.json`, без lifecycle-скриптов; повторный запуск использует кеш. Загрузка требует доступа к `nodejs.org` и `registry.npmjs.org`.

Окно запуска оставьте открытым. **Ctrl+C** останавливает приложение. Повторный BAT открывает уже запущенный экземпляр. По умолчанию сервер использует `http://127.0.0.1:8765`; при занятом порте проверяет следующие 31 порт. Для другого начального порта задайте `KAGEMIYURA_PORT` от 1024 до 65504.

## Что работает

- Отдельный аватар Кагэмиюры открывает и закрывает окно чата; история и настройки находятся на своих страницах. Закрытие окна не удаляет переписку и не останавливает текущий ответ — для этого есть кнопка «Остановить».
- Чистая главная. Правая кнопка мыши по аватару или долгое нажатие на сенсорном экране открывают настройки его образа, магии, частиц и движения. Настройки сохраняются в браузере на данном устройстве, сбрасываются в разделе «Инструменты» и не обращаются к Cloud.ru. Настроение движения меняет анимацию картинки, но не личность и не ответы ИИ. Огонь — декоративный эффект за нижней частью изображения, а не отслеживание отдельных хвостов.
- Потоковые ответы Cloud.ru, остановка генерации, понятные сообщения об ошибках.
- Постоянный архив чатов в `data/conversations.sqlite`: восстановление после перезагрузки, поиск по названию и тексту с поддержкой русского регистра, переименование, скачивание JSON и удаление. Новый разговор сохраняет предыдущий.
- Сообщение сохраняется перед запросом к модели, полученный ответ — перед завершением потока. Во время генерации частичный текст сохраняется не чаще двух раз в секунду. После аварийного завершения незаконченный ответ отмечается как прерванный.
- Сохранение ключа на диске, загрузка списка моделей и проверка выбранной модели.
- Лимит длины ответа от 64 до 4096 токенов; ограничение отправляемого контекста последними 23 сообщениями и 60 000 символами.
- Отсутствие фоновых запросов, автоматических повторов и опроса Cloud.ru. Проверка модели выполняет отдельный запрос с `max_tokens: 1`; входные и служебные токены также могут тарифицироваться.
- Локальный сервер на loopback с проверками Host/Origin, ограничением размера JSON и политикой CSP.
- Защита от параллельной установки зависимостей и двойного запуска сервера.

**Границы версии 0.2:** это чат с постоянным архивом, а не система автономных агентов. Семантический поиск, PostgreSQL/pgvector, извлечение знаний, фоновые задачи, работа в трее и автоматическое обновление приложения пока не реализованы. При резком отключении могут потеряться последние части текущего ответа после контрольной записи; ранее сохранённые сообщения остаются. Данные из других разговоров не отправляются в модель автоматически. Помощница не имеет доступа к файлам и GitHub через чат. Подключение Cloud.ru требует собственного ключа и доступной модели. Проверки используют имитацию API и не расходуют токены; настоящий аккаунт проверяется пользователем в настройках.

## Данные и перенос на другой компьютер

| Путь | Назначение |
| --- | --- |
| `data/conversations.sqlite` | Разговоры и сообщения; база создаётся автоматически |
| `data/cloudru-settings.json` | Ключ Cloud.ru, модель и лимит ответа |
| `data/logs/launcher.log` | Диагностика BAT и подготовки |
| `data/logs/application.log` | Диагностика запуска приложения |
| `.runtime/` | Переносной Node.js, кеш npm, метки сборки и сведения о процессе |
| `dist/` | Собранный сервер и интерфейс |

Папки `data`, `.runtime`, `dist`, `node_modules` исключены из Git. Ключ не возвращается браузеру, не записывается в журналы и отправляется только на официальный API Cloud.ru. Он хранится в локальном JSON открытым текстом: доступ к папке проекта должен быть только у вас. Во время чата Cloud.ru получает текст последних сообщений выбранного разговора в пределах лимита. Архив и поиск работают локально, без обращений к модели. История также хранится на диске без шифрования.

Для переноса остановите приложение и скопируйте всю папку проекта вместе с `data`. Для резервной копии переписки и настроек скопируйте `data` при остановленном приложении. Не удаляйте её при обновлении исходного кода. Для смены архитектуры компьютера можно удалить `.runtime` и `node_modules`, сохранив `data`, затем снова запустить BAT. Автоматического резервного копирования в этой версии нет.

Пути обрабатываются через аргументы процессов и файловые API, без `Invoke-Expression` и `call`. Windows-проверка запускает BAT в папке с кириллицей, пробелами, `%`, `!`, `^`, `&`, скобками и квадратными скобками. Полностью произвольную длину пути гарантировать нельзя: если ОС или антивирус блокируют распаковку, перенесите проект ближе к корню диска, например `D:\Kagemiyura`.

## Разработка

```sh
npm ci --ignore-scripts
npm run check
npm test
npm start
```

`npm start` собирает TypeScript при изменениях и запускает приложение. `npm run build` — отдельная чистая сборка. `KAGEMIYURA_NO_BROWSER=1` отключает открытие браузера. Windows BAT дополнительно поддерживает переменные `KAGEMIYURA_FORCE_PORTABLE=1`, `KAGEMIYURA_PREPARE_ONLY=1`, `KAGEMIYURA_NO_PAUSE=1` для CI и диагностики.

CI выполняет проверку типов, API, сохранения и восстановления истории и запуска на Ubuntu и Windows. Проверка запуска работает в отдельной временной копии проекта, чтобы её пересборка не удаляла файлы API-тестов. На Windows дополнительно скачивает переносной runtime, проверяет BAT в сложном пути и отсутствие повторной установки зависимостей.

Официальные спецификации: [Cloud.ru API](https://cloud.ru/docs/foundation-models/ug/topics/api-ref__specs), [Node.js 24.22.2 и контрольные суммы](https://nodejs.org/dist/v24.22.2/SHASUMS256.txt).
